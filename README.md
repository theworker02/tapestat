# tapestat

Tape lightweight stat statistics from stdin samples.

**Site:** https://theworker02.github.io/tapestat/

## Install / run

```bash
git clone https://github.com/theworker02/tapestat.git
cd tapestat
node src/cli.js
node --test
```
